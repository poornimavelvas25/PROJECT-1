# PROJECT-1
Log File Analyzer for Intrusion Detection

## Project Overview

The Log File Analyzer for Intrusion Detection is a Python-based security tool designed to detect suspicious activities from system and web server logs.

This project simulates basic SOC (Security Operations Center) monitoring by identifying potential security threats such as brute-force attacks, port scanning, and unusual traffic patterns.

The tool parses log files (Apache & SSH), analyzes patterns, and generates alerts with evidence.

## Objective

Parse and analyze Apache and SSH log files

Detect common attack patterns

Identify Indicators of Compromise (IoCs)

Generate alert reports

Visualize suspicious activity trends.

## Conclusion

The Log File Analyzer for Intrusion Detection demonstrates how log monitoring can detect early-stage cyber attacks.

This project strengthens SOC skills in:

Log parsing

Threat detection

Alert generation

Incident reporting

It provides a practical understanding of how real-world security monitoring systems operate.
